from Google's official developer branding page on 14 October 2026:

- Asset: https://developers.google.com/static/youtube/images/developed-with-youtube-sentence-case-dark.png
- Guidelines: https://developers.google.com/youtube/terms/branding-guidelines

YouTube's trademarks remain its property. Use follows the branding guidelines,
not the project's code license. The homepage displays the complete logo on
white, preserves its proportions, links it to YouTube, and separates it from
Comment Lens's own name. Its surrounding text explains that live integration
is planned and the current preview uses handwritten data.
